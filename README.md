# ClipPilot AI

A simple landing page for a YouTube-to-short-clips AI product.

## Run locally

Open `index.html` in a browser, or use a local server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files

- `index.html` — main website layout
- `styles.css` — visual styling
- `script.js` — small interactive submit behavior

## Idea

This project is a polished mockup of an AI app that:
- accepts a YouTube URL
- finds funny or important moments
- creates short clips
- adds automatic captions
- exports social-ready content
